============================================================
AI HERB LAB — 인터랙션 고정 타이밍 정리
============================================================
기준 코드: 2026-06-11
* 모든 시간은 코드에서 직접 확인한 값
* "가변" = 관람객 행동 또는 영상 길이에 따라 달라짐


────────────────────────────────────────────
화면 흐름 순서대로
────────────────────────────────────────────

[0] IDLE (대기 / 환영)
   · 사람 감지 후 → Intro 진입까지 대기 ... 2.5초   (idleEntryDwellMs, config)
   · 환영 텍스트 morph in .............. 2초     (morphMs: 2000)
   ※ Enter 키도 동일하게 2.5초 대기 후 Intro로 넘어감

[1] INTRO (4장 슬라이드)
   · 슬라이드 1장당 .................... 5초     (slideMs, config)
   · 4장 전체 ......................... 20초    (5초 × 4)
   · 슬라이드 텍스트 morph ............. 1.8초   (morphMs: 1800)

[2] INTRO FINALE (CTA)
   · 화면 유지 후 → SeedSelect ......... 5초     (HOLD_MS)
   · 텍스트 morph in .................. 2초     (morphMs: 2000)

[3] SEED SELECT (가전 선택)
   · 가전 위 게이지 차오름 (선택 확정) .. 5초     (DWELL_MS)  ← 가변(관람객)
   · 선택 후 흡수 애니메이션 ........... 0.9초   (ABSORB_MS)
   · 가이드 텍스트 morph .............. 1.8초   (morphMs: 1800)

[4] ANALYZING (관람객 분석)
   · 전체 길이 ........................ 18초    (analyzingMs, config)
   · 라벨 텍스트 morph ................ 1.8초   (morphMs: 1800)

   18초 내부 단계 비율 (PixelGridDissolve):
     IDLE  (웹캠 그대로) ....... 0 ~ 10%  →  0 ~ 1.8초
     IRIS  (픽셀 형성) ........ 10 ~ 30%  →  1.8 ~ 5.4초
     HOLD  (사진 찍는 시간) ... 30 ~ 65%  →  5.4 ~ 11.7초  (약 6.3초)
     DRAIN (중앙 흡수) ........ 65 ~ 90%  →  11.7 ~ 16.2초
     BLACK (검정) ............ 90 ~ 100% →  16.2 ~ 18초

[5] SEED PLANT (씨앗 심기 영상)
   · 영상 길이 ........................ 가변    (영상 ended 이벤트로 전환)
   · 안전망 (영상 안 끝날 때) .......... 60초    (after 60000)
   · 영상 에러 시 대기 후 전환 ......... 3초     (after 3000)
   · 가이드 텍스트 morph .............. 1.8초   (morphMs: 1800)

[6] BLOOM (개화)
   · 자동 재생 시작까지 대기 ........... 3초     (AUTO_PLAY_DELAY_MS)
   · 영상 재생 (3초 이후) ............. 가변    (영상 ended 이벤트로 전환)
   · 안전망 (영상 멈출 때) ............ 90초    (IDLE_SAFETY_MS)
   · 가이드 텍스트 morph .............. 1.8초   (morphMs: 1800)
   ※ t=0 텍스트 표시 → 3초 후 텍스트 교체 + 영상 자동 재생 → 영상 끝나면 Card로

[7] CARD (엔딩 토큰)
   · 토큰 노출 후 → Idle 복귀 ......... 30초    (cardResetMs, config)
   · 가이드 텍스트 morph .............. 1.8초   (morphMs: 1800)


────────────────────────────────────────────
공통 (모든 화면)
────────────────────────────────────────────
   · 화면 전환 크로스페이드 ............ 0.8초   (StateMachine wait 800)
   · 텍스트 사라질 때 morph out ....... 0.7초   (morphOutGuide 700)


────────────────────────────────────────────
한 사이클 최소 소요 시간 (관람객이 빠르게 진행 시)
────────────────────────────────────────────
   Idle (감지 후 대기) ............. 2.5초
   Intro (4슬라이드) ............... 20초
   IntroFinale ..................... 5초
   SeedSelect (선택 최소) .......... 5.9초  (5 + 0.9)
   Analyzing ....................... 18초
   SeedPlant ....................... 영상 길이 (예: 5~10초)
   Bloom (대기 + 영상) ............. 3초 + 영상 길이
   Card ............................ 30초
   전환 페이드 (7회 × 0.8초) ....... 약 5.6초
   ---------------------------------------------
   총 ≈ 약 95초 + 심기영상 + 개화영상


────────────────────────────────────────────
config/assets.json 에서 바로 조정 가능 (코드 수정 X)
────────────────────────────────────────────
   "idleEntryDwellMs": 2500    // Idle 대기
   "seedSelectDwellMs": 5000   // ※ 정의는 있으나 SeedSelect는 코드 상수 DWELL_MS 사용 중
   "analyzingMs": 18000        // 분석 화면 전체
   "cardResetMs": 30000        // 토큰 화면 유지
   "slideMs": 5000             // Intro 슬라이드 1장당

────────────────────────────────────────────
⚠️ 주의
────────────────────────────────────────────
seedSelectDwellMs(config, 5000) 와 SeedSelectState 내부의 DWELL_MS(코드, 5000)는
값은 같지만, SeedSelect는 config을 안 읽고 코드 상수를 사용함.
→ config만 바꾸면 SeedSelect 게이지 시간은 안 바뀜. 코드(DWELL_MS)를 직접 수정해야 함.
